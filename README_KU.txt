KurdAI — وەشانی چاککراوەی ڤیدیۆ

دوگمەی دروستکردن بە ڕێڕەوی ڤیدیۆی Veo بەستراوەتەوە. وێنەی ڕەفەرەنس، قەبارەی 16:9 و 9:16، Extensionی ڤیدیۆی پێشوو، بینین و داگرتن لە کۆددا جێبەجێ کراون.

تاقیکردنەوەکانی ناوخۆ بە وەڵامی ساختەی Google ئەنجام دەدرێن؛ ئەمە بە مانای دروستبوونی ڤیدیۆی ڕاستەقینە نییە. تا GitHub و Cloudflare پەیوەست نەکرێن و ڕەزامەندیی خەرجی تاقیکردنەوە نەدرێت، بڵاوکردنەوە و تاقیکردنەوەی بە پارە تەواو نابێت.

پلانی نرخ و Credits لە docs/PRICING_KU.md ـدایە؛ مۆدێلە هەرزانەکان هێشتا نەبەستراون و پارەدان چالاک نەکراوە. وردەکارییە تەکنیکییەکان لە README.md و تاقیکردنەوەکان لە TEST_REPORT.txt ـدان.
