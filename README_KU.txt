KurdAI — پەکێجی پەرەپێدان

ئەم پەکێجە ڕووکارەکەی ئێستای KurdAI دەپارێزێت و بنەمای Cloudflare Worker + D1 زیاد دەکات.

ناوەڕۆک:
- public/index.html: ڕووکارەکەی ئێستا.
- worker.js: API ـی سەرەتایی بۆ تۆمارکردن، پشتڕاستکردنەوەی ئیمەیڵ، چوونەژوورەوە و کرێدیتی ڕۆژانە.
- schema.sql: خشتەکانی داتابەیس.
- wrangler.toml: ڕێکخستنی Worker و static assets؛ database_id دەبێت پڕ بکرێتەوە.
- TEST_REPORT.txt: ئەو تاقیکردنەوانەی ئەنجام دراون و ئەو بەشانەی هێشتا تەواو نین.

تاقیکردنەوەی ناوخۆیی:
- کۆدی JavaScript لە ڕووی syntax ـەوە تاقی کراوەتەوە.
- schema.sql بە سەرکەوتوویی لە SQLite جێبەجێ کرا.
- کرێدیتی خۆڕایی ڕۆژانە لە نیمەشەوی فینلاند نوێ دەبێتەوە؛ کرێدیتەکانی ڕۆژانی پێشوو کۆ نابنەوە.

پێش بڵاوکردنەوە:
1) D1 دروست بکە و schema.sql جێبەجێ بکە.
2) EMAIL_API_KEY و EMAIL_FROM و پێشکەشکەری ئیمەیڵ ڕێکبخە.
3) API ـەکە بە ڕووکارەکە ببەستەوە.
4) rate limiting، خەرجکردنی کرێدیت، پێوەکراوی ڤیدیۆی AI و پارەدان تەواو بکە.
5) تاقیکردنەوەی end-to-end و ئاسایش بکە.

گرنگ: ئەمە هێشتا خزمەتگوزاریی تەواو و ئامادەی بەکارهێنانی گشتی نییە. API key یان وشەی نهێنی لە کۆدی گشتی دابنێ.

بۆ بڵاوکردنەوە، Cloudflare Wrangler CLI یان Git-based deployment پێویستە؛ Upload static files بە تەنها API ـەکە چالاک ناکات.
