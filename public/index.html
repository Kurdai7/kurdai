بیرۆکەکەت بکە بە ڤیدیۆ

چیرۆکەکەت بنووسە، شێوەزاری کوردی هەڵبژێرە و ئامادەبە بۆ دروستکردنی ڤیدیۆی AI.

دروستکردنی ڤیدیۆی AI بۆ خەڵک هێشتا چالاک نییە. کوالێتی سۆرانی و بادینی و دروستکردنی ٧٠ چرکە هێشتا پشتڕاست نەکراونەتەوە. هیچ پارەیەک بۆ دروستکردنی ڤیدیۆ لێرە وەرناگیرێت.

ئەکاونتی KurdAI

هەژمار دروست بکە یان بچۆ ژوورەوە بۆ بینینی کرێدیتەکانت.

کرێدیت: پێویستە بچیتە ژوورەوە. پشتڕاستکردنەوەی ئیمەیڵ پێویستە.

ڤیدیۆی نوێ دروست بکە

وردەکارییەکان دیاری بکە بۆ ئامادەکردنی ڤیدیۆکەت.

Veo: داواکردنی سۆرانی؛ کوالێتیی دەنگ و شێوەزار هێشتا تاقی نەکراوەتەوە. دەنگ لە نرخی Veo دایە؛ TTS ـی جیاواز چالاک نییە.

Extension تەنها بۆ ڤیدیۆی Veo بە 720p ـە کە لەم ئەکاونتە دروست کراوە و لە ٤٨ کاتژمێری ڕابردوودا هێشتا بەردەستە.

ئەمە کلیپێکی نوێ لەو وێنەیەوە دەست پێ دەکات؛ بە خۆکار لەگەڵ ڤیدیۆی پێشوو یەک ناخات.

PNG یان JPEG، هەر وێنەیەک تا ٤ MiB. وێنەکان یارمەتی پاراستنی ناسنامە دەدەن؛ یەکسانیی تەواو مسۆگەر نییە.

دروستکردنی ڤیدیۆ خەرجی Google API هەیە. کرێدیتی ڕۆژانەی پیشاندراو لێرە پارەی Google نادات. ئێستا دروستکردن بۆ ئەکاونتی تاقیکردنەوەی ڕێکخراوە.

کلیپی نوێ: ٤، ٦ یان ٨ چرکە؛ وێنەی ڕەفەرەنس و 1080p پێویستیان بە ٨ چرکە هەیە. Extension هەر جار ٧ چرکە زیاد دەکات. دیالۆگی سۆرانی داوا دەکرێت، بەڵام Google کوالێتییەکەی مسۆگەر ناکات.

کرییدیتی کڕدراو

Omni 1.1 Flash — بە یەک پرۆمپت

پرۆمپتی سەرەوە بەکاردێت. Omni دیمەنەکان بە ناسنامەی ڤیدیۆی پێشوو بەردەوام دەکات و دەبنە یەک MP4 بە دەنگەوە. کوالێتی شێوەزار و جێگیری ڕوخسار و دەنگ هێشتا بە API تاقی نەکراونەتەوە.

ماوەی هەڵبژێردراو بۆ بەشی نوێیە؛ دەرئەنجام تەنها بەردەوامکردنەکەیە. زمان و ڕەهەندی ڤیدیۆی پێشوو دەپارێزرێن. کوالێتی بەردەوامی هێشتا بە AI تاقی نەکراوەتەوە.

Omni ڕاستەوخۆ بە دەق یان وێنە کار دەکات. تا سێ ڕەفەرەنس ڕوخسار و جل ڕوونتر دەکەن؛ یەکسانیی تەواو گەرەنتی نییە. Wan بەبێ وێنە، خەرجی وێنەی سەرەتایی زیاد دەکات.

نرخی Admin = خەرجیی API و خەرجیی ڕاستەقینەی پرۆسێسکردن. قازانجی فرۆشتن زیاد ناکرێت. تا کۆی خەرجی دیاری نەکرێت، دروستکردن داخراوە. دووبارەکردنەوەی داواکاریی بە پارە بە خۆکار ناکرێت.
