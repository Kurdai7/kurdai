# KurdAI — ٧٠ چرکە، پشکنینی ٢٠٢٦/١٠/١٤

ئەمە کۆدی زیادکراوە لەسەر هەمان لقی پڕۆژە؛ هێشتا لە kurdai.net بڵاو نەکراوەتەوە و هیچ دروستکردنێکی AI بە پارە تاقی نەکراوەتەوە.

## ئایا یەک داواکاریی ٧٠ چرکە هەیە؟

لە API ـە پشکنراوەکاندا، بەڵگەی تەواو بۆ مۆدێلێکی هەرزان بە دەرئەنجامی native ـی ٧٠ چرکە و نرخێکی پشتڕاستکراو نەدۆزرایەوە. ئەمە بانگەشەی ئەوە نییە کە هیچ مۆدێلێک لە جیهاندا ناتوانێت.

- Wan2.2 I2V Flash: بە فەرمی ٥ چرکەی جێگیر؛ Wan2.7: ٢–١٥ چرکە.
- Veo 3.1: کلیپی کورت و extension ـی ٧ چرکە؛ بۆ درێژکردنەوە پێویست بە چەند داواکارییە. ٨ + ٩ × ٧ = ٧١ چرکە و پێویستی بە بڕینی ١ چرکە هەیە. نرخ و شێوازی ژماردنی extension دەبێت پێش کاراکردنی ئەم ڕێگایە بە تایبەتی پشتڕاست بکرێنەوە؛ لە quote ـی Wan دا تێکەڵ نەکراوە.
- LongCat-Video بە مۆڵەتی MIT هەیە و کۆدی continuation ـی چەند پارچەیی هەیە. API ـی fal هەڵبژاردنی num_frames/fps هەیە، بەڵام schema ـە پیشاندراوەکە پشتگیریی ٧٠ چرکە بە یەک داواکاری بە ڕوونی پشتڕاست ناکات. GPU و خەرجیی ڕاستەقینەی self-hosting تاقی نەکراونەتەوە؛ بە خۆڕایی ناژمێردرێت.

## نرخ بۆ Admin

بنەما: €1 = $1.1188، نرخی ECB لە ١٣/١٠/٢٠٢٦؛ ئەمە نرخی مرجەعیە، نەک گەرەنتی نرخی بانک.

| ڕێگا | حسابی API بۆ یەک ڕەنەی سەرکەوتوو | نزیکەی یۆرۆ |
|---|---|---:|
| Wan Flash 480p + وێنەی نوێی FLUX Schnell | ١٤ × ٥ × $0.015 + $0.003 | €0.9412 |
| Wan Flash 480p بە وێنەی خۆت | ٧٠ × $0.015 | €0.9385 |
| Wan Flash 720p + وێنەی نوێ | ٧٠ × $0.036 + $0.003 | €2.2551 |
| Wan A14B Turbo لە fal، 480p — کاندیدی هەرزانتر | $0.05 بۆ هەر ڤیدیۆ؛ ئەگەر هەر یەکە ٥ چرکە بێت: ١٤ × $0.05 + $0.003 | €0.6284 بە مەرج |

کاندیدی fal هێشتا چالاک نەکراوە: نرخی هەر ڤیدیۆکە دیارە، بەڵام schema ـی پشکنراو ماوەی جێگیری ڤیدیۆکەی دیاری ناکات؛ تا ماوە و خەرجیی واقعی پشتڕاست نەکرێنەوە، نرخەکە بە نرخی تەواوی ٧٠ چرکە نافرۆشرێت. Wan Fast 5B text-only هەرزانترە، بەڵام پشتگیریی دوا فڕەیمی پێشوو لەو endpoint ـەدا نییە؛ نرخی ١٤ کلیپی سەربەخۆ بە نرخی بەردەوامیی کارەکتەر نیشان نادرێت.

نرخەکانی سەرەوە **خەرجیی API ـن، کۆی پسوڵەی کۆتایی نین**. خەرجیی سێرڤەری FFmpeg، هەڵگرتن/داگرتن، گۆڕینی دراو و باجی واقعی هێشتا دیاری نەکراون. کۆی نرخی تەواو تا دیاریکردنی ئەمانە ناتوانرێت بە ڕاستی بگوترێت. لە سیستەمەکەدا totalEUR = null و دوگمەی دروستکردن داخراوە تا ئەم نرخانە ڕێک نەخرێن. هیچ قازانجی فرۆشتن، credits، کرێی checkout ـی کڕیار یان باجی خەیاڵی قازانج بۆ Admin زیاد ناکرێت.

وێنەی FLUX بە 848×480 یان 480×848 دروست دەکرێت، هەردووکیان کەمتر لە یەک megapixel ـن؛ نرخەکە $0.003 بۆ یەک MP ـی بەرزکراوە. بۆ ڕوخسارێکی دیاریکراو، وێنەی خۆت باشترە. نرخەکان هەڵسەنگاندنی list-price ـن؛ دەبێت لەگەڵ usage و پسوڵەی دابینکەر بەراورد بکرێن. تاقیکردنەوە یان دووبارەکردنەوە خەرجیی جیا هەیە و بە خۆکار ئەنجام نادرێت.

## چی زیاد کراوە؟

١. یەک پرۆمپت و ناسنامەی کارەکتەر، وێنەی ئارەزوومەندانە، 16:9/9:16 و 480p/720p.
٢. quote ـی خەرجی پێش دروستکردن؛ ڕەزامەندی بە هەمان کۆی نرخ بۆ هەمان پرۆمپت. گۆڕینی پرۆمپت/نرخ quote هەڵدەوەشێنێتەوە.
٣. وێنەی سەرەتایی بە API یان وێنەی بەکارهێنەر؛ پاشان ١٤ کلیپی I2V بە ڕیز. دوا فڕەیمی هەر کلیپ دەبێتە سەرەتای دواتر. seed و ڕێنمایی ناسنامە جێگیرن.
٤. worker ـی دروستکردنی درێژ لە سێرڤەری Node/FFmpeg دەڕوات؛ داخستنی پەڕەکە کارەکە ناوەستێنێت. manifest و task ID لە دیسکی بەردەوامدا پاشەکەوت دەکرێن.
٥. یەک MP4 ـی بێ دەنگ بە ٧٠ چرکە؛ FFprobe ماوەکە پشکنین دەکات پێش ready. کلیپی کورتتر بە دووبارەکردنەوەی بە پارە ناگۆڕدرێت؛ ڕادەوەستێت.
٦. ئیمەیڵی پشتڕاستکراوی Admin تەنها دەستگەیشتن هەیە. API keys لە سێرڤەردان. داواکاریی دووبارە بە هەمان ID خەرجیی نوێ دروست ناکات. کێشەی ناڕوونی ناردن دەبێتە uncertain؛ لە کۆنسۆڵی دابینکەر دەبێت پشکنین بکرێت، نەک خۆکار دووبارە بکرێتەوە.

**گەرەنتییەکان و سنوورەکان:** ئەم ڕێگایە native Video Extension نییە؛ last-frame I2V + یەکخستنە. دوا فڕەیم و ناسنامە یارمەتیدەرن، بەڵام گەرەنتیی ڕوخساری یەکسان و جووڵەی بێ پچڕان نادەن. سیستەمی پشکنینی ئۆتۆماتیکی ڕوخسار زیاد نەکراوە. دەنگ، دیالۆگی سۆرانی، dubbing و lip-sync لە نرخەکەدا نییە. تێگەیشتن لە پرۆمپتی سۆرانی لەم مۆدێلەدا تاقی نەکراوەتەوە؛ ڕێنمایی جووڵە بە ئینگلیزی باشتر پشتگیری کراوە. دابەشکردنی پرۆمپت بە ڕێنمایی جێگیری بەردەوامبوونە، نەک پلاندانانی زیرەکیی دیمەن بە LLM.

## چی هێشتا نەکراوە؟

- GitHub write پێشتر 403 دا؛ push و deployment نەکراون. هەموو گۆڕانکارییە پێشووەکان لە git پارێزراون.
- Cloudflare هێشتا دەستگەیشتنی deployment نییە. Node/FFmpeg سێرڤەرێکی جیا دەوێت؛ لە Cloudflare Workers ـی ئاسایی جێبەجێ نابێت.
- ئەکاونتی دابینکەرەکان و مۆڵەت/پارەدان و نرخی میوانداری دەبێت پێش چالاککردن پشتڕاست بکرێنەوە؛ هیچ ئەکاونت یان گرێبەستێک دروست نەکراوە.
- هیچ ڤیدیۆی AI ـی ٧٠ چرکە بەڕاستی دروست نەکراوە. تاقیکردنەوەی FFmpeg بە ڤیدیۆی دەستکردی تاقیکردنەوە بووە، بەبێ خەرجیی API.
