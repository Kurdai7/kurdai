## چاکسازیی ئەم وەشانە

- پێش کلیپی کورت، دوگمەی بێ پارەی پیشاندانی خەرجی API بە یۆرۆ هەیە. نرخی Admin قازانجی فرۆشتنی تێدا نییە. نرخەکە خەمڵاندنی نرخنامەی فەرمییە، نەک پسوولەی کۆتایی؛ باج، بانك و سێرڤەر لێی دەرەوەن.

- keep_vars بۆ پاراستنی گۆڕاوەکانی Dashboard لە Git deploy چالاک کراوە. هیچ Secret ـێک لە کۆد نییە.

## چی هێشتا ماوە؟

٧٠ چرکەی ئۆتۆماتیکی: کۆد بۆ ١٤ کلیپی پەیوەست، وەرگرتنی دوا فڕەیم و یەک MP4 هەیە. FFmpeg بە فایلە دەستکردە ناوخۆییەکان تاقی کراوەتەوە، بۆ هەردوو 16:9 و 9:16. ئەمە بەڵگەی سەرکەوتنی ڤیدیۆی AI نییە.

بۆ کارکردنی ڕاستەقینە، پرۆسێسەرەکە پێویستی بە میوانداری Node 24/FFmpeg و دیسکی هەمیشەیی و HTTPS، دەستگەیشتنی Alibaba/fal و ڕێکخستنی خەرجییەکان هەیە. هیچ میواندارییەک نەکڕدراوە. Cloudflare Worker ـی ئاسایی ئەم executable ـی FFmpeg ـە جێبەجێ ناکات. LONG_VIDEO_SERVICE_URL و پەیوەندیی پارێزراوی پرۆسێسەر لەبەردەست نییە؛ کلیپی درێژ نابێت وەک چالاک ڕیکلام بکرێت.

سۆرانی و بادینی لە پرۆمپت و تۆماری داواکاری جیاوازن. گۆڕینی زمان لە Extension ڕەت دەکرێتەوە. بەڵام کوالێتیی ڕاستەقینەی دەنگ، شێوەزار، lip-sync و جێگیریی دەنگی کارەکتەر تاقی نەکراونەتەوە. TTS ـی جیاواز و یەکخستنی دەنگ هێشتا چالاک نییە؛ ٧٠ چرکەی دەنگدار بە ڕوونی داخراوە.

ڕوخسار و جل و کامێرا بە reference/دوا فڕەیم و پرۆمپت پارێزراو دەکرێن، بەڵام جێگیریی تەواو گەرەنتی نییە. هەڵسەنگاندنی بینراوی کارەکتەر هێشتا نییە.

403: پەڕەی سەرەکی kurdai.net لە Cloud Browser کرایەوە و کۆدی بڵاوکراوە دیار بوو. /api/health لەو وێبگەڕە بە ERR_BLOCKED_BY_CLIENT ڕاگیرا؛ ئەمە بەڵگەی شکستی API یان bot detection نییە. Cloudflare Dashboard ـی ئەم سێشنە هێشتا دەستگەیشتنی پشتڕاستکراوی نییە؛ ڕێگریی sign-in بە سڕینەوەی پاراستنەکان چارەسەر نەکراوە.

## بەردەوامبوونی دواتر — ٢٨ تاقیکردنەوە

کێشەی داواکردنی fal بۆ وێنەی بەکارهێنەر چارەسەر کرا؛ بۆ ئەو ڕێگایە تەنها دابینکەری I2V پێویستە. نرخە بەتاڵەکان ئیتر وەک سفر دانانرێن. پشکنینی بێ پارەی سێرڤەری ٧٠ چرکە زیاد کرا، بەبێ ناردنی داواکاریی AI.

تاقیکردنەوەیەکی تەواوی نوێ Worker بە سێرڤەری HTTP ـی ڕاستەقینەی ناوخۆ بەستەوە، نرخنامە/ڕەزامەندی پشکنی، ١٤ دەرئەنجامی دەستکردی بە FFmpeg یەکخست و یەک MP4 ـی ٧٠ چرکەیی لە ڕێگای داگرتنی پارێزراو تاقی کردەوە. ئەمە نموونەی AI نییە؛ API ـە دەرەکییەکان لە تاقیکردنەوەکە قەدەغە بوون. هەموو ٢٨ تاقیکردنەوە و Build ـی ناوخۆ سەرکەوتوون.

بۆ بەکارهێنانی ڕاستەقینە، دەستگەیشتن بە میوانداری هێشتا پێویستە. Render وەک پەیوەستکەر بەردەستە، بەڵام هێشتا پەیوەست نەکراوە و هیچ سێرڤەر یان دیسکێک دروست نەکراوە. پلانی بێ پارەی Render دیسکی هەمیشەیی نییە؛ بۆ paid jobs نابێت وەک ڕێگای هەمیشەیی بەکاربهێنرێت. پێش هەر تەرخانکردنی میوانداریی پارەدار، خەرجییەکە دەبێت بە جیاوازی قبوڵ بکرێت. وێنەی Docker لەم ژینگەیە build نەکرا، چونکە Docker بەردەست نییە.


## Render — نوێکردنەوەی دوایین، ٢٠٢٦-١٠-١٤

Render ئێستا پەیوەستە. خزمەتگوزارییەکی بەخۆڕایی لە Frankfurt بە ناوی kurdai-processor-staging دروست کرا و Build و Deploy ـی Docker سەرکەوتوون. /healthz بە HTTPS وەڵامی 200 دا و FFmpeg، ffprobe و libx264 کار دەکەن. ٢٨ تاقیکردنەوە، syntax و Worker dry-run دووبارە سەرکەوتوون.

ناونیشانی staging لە wrangler.toml دانراوە. LONG_VIDEO_SERVICE_SECRET تەنها لە Render پارێزراوە؛ هەمان Secret دەبێت بە شێوەی پارێزراو لە Cloudflare دابنرێت. دەستگەیشتنی Dashboard ـی Cloudflare لەم سێشنەدا بەردەست نییە. هیچ Secret ـێک لە کۆد یان چات دانەنراوە.

LONG_VIDEO_ENABLED=false؛ هیچ API Key ـی دابینکەری پارەدار دانەنراوە و هیچ داواکارییەکی ڤیدیۆ یان دەنگی پارەدار نەکراوە. پلانی بەخۆڕایی دیسکی هەمیشەیی نییە؛ بۆ کارە پارەدارەکان بەکارناهێنرێت. دیسکی هەمیشەیی و میوانداریی گونجاو پێویستیان بە ڕەزامەندیی خەرجی هەیە. دەنگی سۆرانی/بادینی و جێگیریی ڕوخسار هێشتا بە AI ـی ڕاستەقینە تاقی نەکراونەتەوە.

## نوێکردنەوەی ٢٠٢٦-١٠-١٥ — Omni

پەیوەندی پارێزراوی kurdai.net بە Render لەلایەن خاوەنەکە پشتڕاست کرایەوە. کۆدی Omni ئێستا بە فۆڕم و نرخنامە و ڕەزامەندییەوە بەستراوە. ماوەی ٥ تا ٧٠ چرکە بە هەنگاوی ٥، سۆرانی و بادینی بە جیاوازی، هەردوو قەبارە و تا سێ وێنە هەن. ڕێگای MP4 دەنگەکە دەپارێزێت.

٤٤ تاقیکردنەوەی بێ پارە، syntax و Build سەرکەوتوون. ٥، ٦٠ و ٧٠ چرکە لە ڕێگای HTTP و FFmpeg بە دەرئەنجامی دەستکرد پشکنران؛ ئەمە ڤیدیۆی دروستکراوی Google نییە. وەشانی نوێی Omni هێشتا پێویستی بە Deploy هەیە.

دروستکردنی ڕاستەقینە هێشتا داخراوە: دەستگەیشتنی Gemini لە سێرڤەر، هەڵگرتنی هەمیشەیی و کۆی خەرجی پشتڕاستکراو پێویستن. بەشی تۆکنە نەزانراوەکان بە سفر دانەنراون. نرخەکە پێشبینییە، نەک پسوڵە یان گەرەنتیی سنووری پارەدان. هیچ پلانی پارەدار یان API ـی پارەدار چالاک نەکراوە.
