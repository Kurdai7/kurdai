# زمانی دیالۆگ و خەرجیی دەنگ — ٢٠٢٦/١٠/١٤

لە هەمان پڕۆژەدا دوو هەڵبژاردەی جیاواز هەن: کوردی سۆرانی (Sorani Kurdish) و کوردی بادینی (Badini Kurdish). ڕێنمایی واژە، ڕێزمان، تەلەفوز و ئاوازی قسە بۆ هەر یەک جیاوازە؛ دەقی دیالۆگ بە خۆکار وەرناگێڕدرێت و نابێت لە شێوەزارێکەوە بۆ ئەوی تر بگۆڕدرێت.

Veo دەنگی ناوخۆی ڤیدیۆ دروست دەکات، بەڵام پشتگیری و دروستیی شێوەزاری سۆرانی و بادینی بە ڤیدیۆی واقعی تاقی نەکراونەتەوە. UI داواکردنی شێوەزار لە گەرەنتی دەنگ جیا دەکاتەوە. ڕێنمایی پرۆمپت بە تەنها ناتوانێت مۆدێل ناچار بکات هەموو وشەیەک بە تەواوی دروست بڵێت. دەنگی native لە نرخی Veo دایە؛ TTS ـی جیاواز لەگەڵی چالاک نییە و خەرجیی دووجار ناژمێردرێت.

زمانی هەر job ـێک پاشەکەوت دەکرێت. Extension پێویستە هەمان زمانی سەرەتا بپارێزێت؛ هەوڵی گۆڕینی سۆرانی بۆ بادینی یان بە پێچەوانەوە لە backend ڕەت دەکرێتەوە پێش ناردنی داواکاریی بە پارە. کلیپە کۆنەکان کە زمانەکەیان نادیارە، بە خەیاڵ سۆرانی دانانرێن؛ پێویستە کلیپی نوێ بە زمانێکی دیاریکراو دەست پێ بکات.

ژمارەی پیت لە ماوەی دەنگ جیاوازە؛ ٧٠ چرکە هەمیشە ١٢٠٠ پیت نییە. Gemini بە token دەژمێرێت و KurdishTTS بە پیت؛ پسوڵە و ژماردنی Unicode پێویستیان بە پشتڕاستکردنەوە هەیە. دەنگی کارەکتەرەکان دەبێت بە voice ID ـی جێگیر هەڵبژێردرێت، نەک بە ناوی شێوەزار تەنها.

## نموونەی خەرجی، نەک quote ـی چالاک

- سۆرانی بۆ ٧٠ چرکە دەنگ: $0.0105 ≈ €0.0094 **تەنها output audio**؛ input tokens و یەکخستن زیاد دەبن. بۆ ٧٠ چرکەی ڤیدیۆی Wan 480p بە وێنەی نوێ، API ـی ڤیدیۆ $1.053 + output audio $0.0105 = $1.0635 ≈ €0.9506، پێش input tokens و میوانداری/یەکخستن/FX/باج.
- بادینی بۆ نموونەی ١٢٠٠ پیت: $0.0072 ≈ €0.0064 **تەنها بەهای top-up ـی پیتەکان**؛ بەشداری، مۆڵەتی گونجاو، ماوەی واقعی دەنگ و یەکخستن هێشتا زیاد دەبن. ئەمە نرخی تەواوی ٧٠ چرکە نییە.
- نرخی ECB بەکارهاتوو: €1 = $1.1188 لە ١٣/١٠/٢٠٢٦. نرخەکانی بانک جیاوازن.

بۆیە لە quote ـی ڤیدیۆی درێژی بە دەنگدا audioAPIUSD و totalEUR هێشتا null ـن و canStart=false. ژمارەی partial estimate بە ڕوونی پیشان دەدرێت، بەڵام بە نرخێکی تەواو نانێردرێت. بێ ڕەزامەندی هیچ TTS API، top-up، بەشداری یان گرێبەستێک جێبەجێ نەکراوە.

## ڕێگای بەردەوامکردن

١. دەقی هەر کارەکتەر بە شێوەزارە هەڵبژێردراوەکە، voice ID ـی جێگیر و کاتی دەستپێکردنی دیالۆگ.
٢. quote ـی تەواو: ڤیدیۆ + دەنگ + بەشی واقعی بەشداری/مۆڵەت + یەکخستن/هەڵگرتن + FX/باجی پەیوەندیدار؛ بۆ Admin بەبێ قازانجی فرۆشتن.
٣. پاش ڕەزامەندی، یەک نموونەی واقعی بە گوێی قسەکەری هەمان شێوەزار پشکنین بکرێت. سۆرانی هەرگیز جێگرەوەی بادینی نابێت.
٤. دەنگ و ڤیدیۆ لە یەک فایل یەک بخرێن؛ ئەمە بە تەنها lip-sync دروست ناکات. lip-sync ـی زمانی کوردی هێشتا پشتڕاست نەکراوەتەوە و خەرجییەکەی لەم ژمارانەدا نییە.

TTS و mux ـی دەنگ هێشتا بە backend ـی دروستکردن پەیوەست نەکراون. ئەوەی جێبەجێ کراوە هەڵبژاردنی شێوەزار، ڕێنمایی جیاواز، قفڵی Extension و ڕێگریکردن لە چالاککردنی دەنگ بە نرخی نادیارە.
